# 🎁 Telegram Gifts & Stars Bot ⭐

Полнофункциональный асинхронный Telegram-бот на Python (`aiogram 3.31+` и `aiosqlite`) для Telegram-групп, который разыгрывает **НАСТОЯЩИЕ Telegram Gifts**, оплачиваемые реальными **Telegram Stars ⭐**.

Никаких виртуальных валют, фейковых балансов или имитаций — бот использует официальные методы **Telegram Bot API 8.0+** (`getAvailableGifts`, `sendGift`, `getMyStarBalance`).

---

## 🌟 Как это работает

```text
Участник пишет сообщение в группе
               ↓
    Проверка шанса (например, 5%)
               ↓
        [ Шанс сработал! ]
               ↓
  Запрос актуального каталога подарков Telegram API
  и проверка баланса Telegram Stars бота
               ↓
  Выбор подходящего реального подарка
               ↓
  Бот отправляет НАСТОЯЩИЙ подарок (sendGift)
  Прямо в профиль пользователя за счет Stars бота!
               ↓
  Анонс победы в группе Telegram 🎉
```

## ⭐ Официальная архитектура Telegram Stars & Gifts

### 1. Как отправляются подарки через Bot API
В версии Telegram Bot API 8.0+ добавлены официальные методы:
* `getAvailableGifts`: Возвращает актуальный список всех реальных подарков в Telegram с их ценой в Stars, стикерами и остатком.
* `getMyStarBalance`: Показывает текущий официальный баланс Telegram Stars бота.
* `sendGift`: Отправляет выбранный подарок пользователю. Стоимость подарка в Stars **списывается с официального баланса самого бота**.

### 2. Откуда у бота Telegram Stars
Чтобы бот мог дарить подарки, на его балансе должны быть Stars. Пополнить баланс бота можно:
* Прямым переводом Stars боту через Telegram (через инвойсы или перевод в профиле бота);
* Оплатой цифровых товаров и услуг внутри бота;
* Через привязанный Telegram Business аккаунт (`transferBusinessAccountStars`).

> [!IMPORTANT]
> **Ограничение безопасности Telegram**: Telegram не позволяет сторонним скриптам скрытно и автоматически списывать Stars с обычного личного аккаунта пользователя без его прямого подтверждения. Поэтому основной и официальный способ автоматической выдачи подарков — это **баланс Stars самого бота** через официальный Bot API.
> 
> В боте также предусмотрена поддержка **MTProto пользовательской сессии** (`Telethon`) для связки с аккаунтом владельца или мониторинга.

## 🤖 Регистрация и настройка в Telegram

### 1. Получение Bot Token
1. Откройте официального бота [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, укажите имя и юзернейм (например, `MyGiftsBot`).
3. Скопируйте полученный **Bot Token**.

### 2. Настройка прав в группе (Privacy Mode)
По умолчанию боты Telegram не видят обычные сообщения в группах. Чтобы бот мог проверять сообщения на выигрыш:
1. В [@BotFather](https://t.me/BotFather) введите `/setprivacy`.
2. Выберите вашего бота и нажмите **«Disable»** (Отключить).
3. Добавьте бота в группу и назначьте его **Администратором**.

### 3. Нужны ли Telegram API ID и API Hash?
* **Для стандартной работы через Bot API (Рекомендуется):** НЕТ, достаточно только `BOT_TOKEN`. Бот использует официальный баланс Stars и метод `sendGift`.
* **Если вы хотите подключить MTProto сессию:** ДА, получите `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org) в разделе «API development tools». Мастер установки запросит их интерактивно.

## 🚀 Установка и запуск

### Вариант A: Linux / macOS
```bash
chmod +x setup.sh start.sh
./setup.sh
```

### Вариант B: Windows
Просто дважды кликните по:
```text
👉 setup.bat
```

### Что делает мастер установки (`wizard.py`):
1. Проверяет наличие Python 3.10+;
2. Создает изолированное окружение `.venv` и ставит зависимости;
3. Запрашивает Bot Token и сразу проверяет его через Telegram API;
4. Отображает текущий баланс Stars бота;
5. Запрашивает ID группы (или оставляет для любых групп);
6. Запрашивает процент шанса выпадения (например, 5%);
7. При необходимости настраивает MTProto-сессию с интерактивным вводом кода подтверждения (пароли никогда не сохраняются в открытом виде);
8. Запускает бота!

Для повторных запусков в дальнейшем:
* На Linux/macOS: `./start.sh`
* На Windows: `start.bat`

## ⚙️ Конфигурация (.env)

```env
# Токен бота от @BotFather (Обязательно)
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Шанс выпадения подарка на каждое сообщение в % (например, 5 = 5%)
GIFT_DROP_CHANCE=5

# ID подключенной группы (например, -1001234567890). Если пусто — работает везде
TARGET_CHAT_ID=

# Максимальная цена подарка в Stars (0 — без ограничений)
MAX_GIFT_PRICE_STARS=50

# Список разрешенных ID подарков (если пусто — разрешены все)
ENABLED_GIFT_IDS=

# Источник Stars: 'bot' (баланс бота) или 'user_session'
STARS_SOURCE=bot

# Опционально: данные MTProto сессии
TELEGRAM_API_ID=
TELEGRAM_API_HASH=
TELEGRAM_PHONE=
SESSION_NAME=secrets/user_session

# База данных истории доставок подарков
DATABASE_PATH=data/bot.db

# Защита от спама (секунд между проверками сообщений одного пользователя)
SPAM_COOLDOWN_SECONDS=3

# ID администраторов для управления через ЛС
ADMIN_IDS=
```

## 🔒 Безопасность

* Файл `.env`, сессии `secrets/*.session`, базы данных SQLite и кэш добавлены в `.gitignore` и защищены от случайной публикации.
* Токены и приватные ключи не хранятся в репозитории.
* При вводе двухфакторного пароля (2FA) для сессий пароль никогда не логируется и не записывается на диск.
