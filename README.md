# 🐻 MishkaBot — Игровой Telegram-бот для групп и чатов

**MishkaBot** — это полнофункциональный асинхронный Telegram-бот на Python (`aiogram 3` + `aiosqlite`), созданный для оживления общения в Telegram-чатах и группах.

Каждое обычное сообщение пользователя имеет шанс получить плюшевую награду — **Мишку** одного из 4 уровней редкости! Участники соревнуются за верхние строчки рейтинга, а администраторы могут прямо из чата настраивать вероятности выпадения.

---

## 🌟 Основные возможности

* 🎲 **Гибкая система вероятностей**: Настраиваемый общий шанс выпадения мишки на каждое сообщение (например, 5%).
* 🧸 **4 типа редкости мишек**:
  * 🧸 **Обычный мишка** (`common`) — базовый шанс: 70%
  * 🐻 **Редкий мишка** (`rare`) — базовый шанс: 20%
  * 🐼 **Эпический мишка** (`epic`) — базовый шанс: 8%
  * 🐨 **Легендарный мишка** (`legendary`) — базовый шанс: 2%
* 🛡️ **Строгая валидация**: Сумма вероятностей редкостей всегда должна составлять ровно 100%. Бот защищает от ошибок конфигурации.
* 💾 **Асинхронная база данных SQLite**:
  * Хранение Telegram ID, username, имени;
  * Счётчики каждого типа мишек и общего количества;
  * Дата первого и последнего выигрыша;
  * Сохранение всех данных при перезапуске.
* 👑 **Интеллектуальная панель администратора**:
  * Администраторы группы определяются автоматически через официальный Telegram API;
  * Изменение шансов на лету с автоматическим сохранением в `.env`.
* 🛡️ **Защита от спама и абуза**:
  * Сообщения ботов не награждаются;
  * Встроенный кулдаун (по умолчанию 3 сек.) между зачетом сообщений одного пользователя;
  * Дедупликация событий для защиты от повторной обработки сообщений.
* ⚡ **Быстрый старт в 1 команду**: Интерактивный установочный скрипт `setup.sh`.

## 📋 Команды бота

### Для всех участников:

| Команда | Описание | Пример вывода |
| :--- | :--- | :--- |
| `/start` | Информация о боте и список доступных команд | Приветственное сообщение с описанием |
| `/me` | Личная коллекция и статистика мишек | 🧸 Обычных: 15, 🐻 Редких: 4, 🎁 Всего: 19 |
| `/top` | Топ-10 коллекционеров мишек чата | 🥇 1. @user — 42 шт. |
| `/chance` | Текущий общий шанс и разбивка по типам | 5% на сообщение (70/20/8/2) |

### Для администраторов чата:

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `/setchance <процент>` | Изменить общий шанс выпадения мишки (0–100%) | `/setchance 7` |
| `/settype <тип> <процент>` | Изменить вероятность выпадения типа (`common`, `rare`, `epic`, `legendary`) | `/settype epic 10` |
| `/stats` | Посмотреть глобальную статистику сообщений и наград | Сообщений: 12,450; Выдано: 620 |
| `/reload` | Принудительно перезагрузить параметры из `.env` | Перезагружает конфигурацию |

> [!NOTE]
> При изменении вероятности типа через `/settype` бот проверяет, чтобы новая сумма всех четырех типов равнялась **100%**. Если сумма не равна 100%, команда отклоняется с подробной подсказкой.

## 🤖 Регистрация и настройка бота в Telegram

### 1. Получение токена через [@BotFather](https://t.me/BotFather)

1. Откройте диалог с официальным ботом [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Введите отображаемое имя бота (например, `Mishka Bot`).
4. Введите юзернейм бота, заканчивающийся на `bot` (например, `my_mishka_super_bot`).
5. Скопируйте полученный **HTTP API Token** (формата `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 2. ВАЖНО: Настройка прав приватности в группах (Group Privacy)

По умолчанию боты в Telegram работают в режиме «Privacy Mode» и видят только команды, начинающиеся с косой черты (`/`). Чтобы MishkaBot мог проверять **каждое обычное сообщение** пользователей и выдавать награды:

1. В [@BotFather](https://t.me/BotFather) отправьте команду `/setprivacy`.
2. Выберите вашего бота из списка.
3. Нажмите кнопку **«Disable»** (Отключить).
4. Вы увидите подтверждение: *«Success! The new value is: DISABLED. Now 'your_bot' will receive all messages in groups.»*

> [!TIP]
> В качестве альтернативы отключению Privacy Mode вы можете просто назначить бота **Администратором группы** (с базовым правом читать сообщения).

### 3. Добавление бота в группу

1. Зайдите в профиль вашего бота в Telegram и нажмите **«Добавить в группу»** (или откройте группу -> «Добавить участников» -> найдите вашего бота).
2. Назначьте бота администратором группы, чтобы ему был открыт доступ к сообщениям и правам чата.

## 🚀 Быстрый запуск (в 1 команду)

Склонируйте репозиторий и запустите скрипт автоматической настройки:

```bash
# Сделайте скрипты исполняемыми
chmod +x setup.sh start.sh

# Запустите автоустановку
./setup.sh
```

### Что делает `setup.sh`:
1. Проверяет наличие Python (3.9+).
2. Создает изолированное виртуальное окружение `.venv`.
3. Устанавливает все необходимые зависимости из `requirements.txt`.
4. Создает рабочие папки (`data/`, `handlers/`, `utils/`).
5. Создает файл `.env` на основе `.env.example`, если он отсутствует.
6. Проверяет переменную `BOT_TOKEN`: если токен не указан, интерактивно запрашивает его ввод в терминале.
7. Сохраняет токен в `.env`.
8. Проверяет корректность токена запросом к Telegram API (`getMe`).
9. Автоматически запускает бота!

### Последующие запуски:
```bash
./start.sh
```

## ⚙️ Конфигурация (.env)

Все параметры бота вынесены в файл `.env`, поэтому вам не требуется редактировать код:

```env
# Токен бота, полученный у @BotFather
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Базовый шанс выпадения мишки на каждое сообщение (в процентах, например 5 = 5%)
MISHKA_CHANCE=5

# Вероятности типов мишек (сумма обязана быть ровно 100%)
COMMON_MISHKA_CHANCE=70
RARE_MISHKA_CHANCE=20
EPIC_MISHKA_CHANCE=8
LEGENDARY_MISHKA_CHANCE=2

# Путь к файлу базы данных SQLite
DATABASE_PATH=data/mishka.db

# Защита от спама: минимальный интервал между зачетными сообщениями пользователя (в секундах)
SPAM_COOLDOWN_SECONDS=3

# Опционально: Telegram ID главных администраторов через запятую (для управления в ЛС)
ADMIN_IDS=
```

## 🧪 Запуск тестов

Проект сопровождается полным набором автоматизированных тестов, проверяющих:
* Валидацию конфигурации (проверка правила 100%);
* Механику генерации случайных чисел (RNG) и статистическое распределение на 10 000 итерациях;
* Базу данных SQLite (транзакции, подсчет статистики, сохранность при перезапуске);
* Анти-спам кулдауны и форматирование ссылок.

Для запуска тестов выполните:
```bash
python3 -m unittest discover tests -v
```
