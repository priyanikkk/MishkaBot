====================================================================
🐻 ИНСТРУКЦИЯ ПО ЗАПУСКУ MISHKABOT НА WINDOWS
====================================================================

Привет! Этот бот готов к работе прямо "из коробки". 
Вам не нужно писать код или разбираться в программировании.

--------------------------------------------------------------------
ШАГ 1. УСТАНОВКА PYTHON (если он еще не установлен)
--------------------------------------------------------------------
1. Скачайте Python с официального сайта:
   https://www.python.org/downloads/
   (подойдет любая версия Python 3.10, 3.11, 3.12, 3.13+)

2. ⚠️ ВАЖНО ПРИ УСТАНОВКЕ:
   На самом первом экране программы установки внизу ОБЯЗАТЕЛЬНО 
   поставьте галочку:
   [v] "Add python.exe to PATH"  (или "Add Python to environment variables")
   Затем нажмите "Install Now".

--------------------------------------------------------------------
ШАГ 2. ПЕРВЫЙ ЗАПУСК И НАСТРОЙКА (В 1 КЛИК)
--------------------------------------------------------------------
1. Откройте папку с ботом.
2. Дважды кликните мышкой по файлу:
   👉 setup.bat

3. Скрипт сам создаст нужные папки и скачает необходимые библиотеки.
4. Когда в черном окне появится вопрос:
   "👉 Вставьте ваш Bot Token и нажмите Enter: "
   Вставьте токен вашего бота (полученный у @BotFather) и нажмите Enter.

Бот автоматически подключится и начнет работать!

--------------------------------------------------------------------
ШАГ 3. ПОСЛЕДУЮЩИЕ ЗАПУСКИ
--------------------------------------------------------------------
Для повторного запуска бота в любое время просто дважды кликните:
👉 start.bat

Чтобы остановить бота — просто закройте окно программы.

--------------------------------------------------------------------
ШАГ 4. НАСТРОЙКА БОТА В TELEGRAM ДЛЯ РАБОТЫ В ГРУППЕ
--------------------------------------------------------------------
Чтобы бот мог видеть сообщения в чате и выдавать за них мишек:

ВАРИАНТ А (Самый простой):
Добавьте бота в вашу группу Telegram и назначьте его АДМИНИСТРАТОРОМ группы.

ВАРИАНТ Б (Без прав администратора):
1. Откройте в Telegram диалог с @BotFather
2. Отправьте команду: /setprivacy
3. Выберите вашего бота
4. Нажмите кнопку "Disable" (Отключить приватный режим)

--------------------------------------------------------------------
ШАГ 5. КОМАНДЫ БОТА
--------------------------------------------------------------------
Для участников чата:
/start   — информация о боте
/me      — личная коллекция мишек
/top     — топ лидеров чата по количеству мишек
/chance  — узнать текущий шанс выпадения

Для администраторов чата:
/setchance 5             — изменить шанс выпадения на 5% (можно любое число от 0 до 100)
/settype common 70       — изменить шанс обычного мишки
/settype rare 20         — изменить шанс редкого мишки
/settype epic 8          — изменить шанс эпического мишки
/settype legendary 2     — изменить шанс легендарного мишки
/stats                   — статистика бота (сколько сообщений обработано и мишек выдано)
/reload                  — перезагрузить настройки

--------------------------------------------------------------------
ГДЕ МЕНЯТЬ НАСТРОЙКИ ВРУЧНУЮ?
--------------------------------------------------------------------
Все настройки хранятся в файле ".env". Вы можете открыть его через Блокнот 
и при необходимости изменить токен или шансы вручную.
