====================================================================
🎁 ИНСТРУКЦИЯ ДЛЯ ПОКУПАТЕЛЯ: TELEGRAM GIFTS & STARS BOT (WINDOWS)
====================================================================

Привет! Этот бот предназначен для розыгрыша НАСТОЯЩИХ Telegram Gifts 
в вашей Telegram-группе за реальные Telegram Stars ⭐.

Бот полностью готов к работе и настраивается в пару кликов.

--------------------------------------------------------------------
ШАГ 1. УСТАНОВКА PYTHON (если еще не установлен)
--------------------------------------------------------------------
1. Скачайте Python с официального сайта:
   https://www.python.org/downloads/
   (подойдет версия Python 3.10, 3.11, 3.12, 3.13+)

2. ⚠️ ВАЖНО ПРИ УСТАНОВКЕ:
   На самом первом экране программы установки внизу ОБЯЗАТЕЛЬНО 
   поставьте галочку:
   [v] "Add python.exe to PATH"  (или "Add Python to environment variables")
   Затем нажмите "Install Now".

--------------------------------------------------------------------
ШАГ 2. ПЕРВЫЙ ЗАПУСК И НАСТРОЙКА (В 1 КЛИК)
--------------------------------------------------------------------
1. Откройте папку с ботом.
2. Дважды кликните мышкой по файлу:
   👉 setup.bat

3. Мастер настройки сам скачает нужные библиотеки и по очереди спросит:
   • Токен бота (от @BotFather в Telegram);
   • Источник Stars (выберите 1 — баланс бота);
   • ID группы (или оставьте пустым, нажав Enter);
   • Процент шанса выпадения подарка (по умолчанию 5%);
   • Максимальную стоимость подарка в Stars (по умолчанию 50 ⭐).

Бот проверит токен, покажет текущий баланс Stars бота и сразу запустится!

--------------------------------------------------------------------
ШАГ 3. ПОПОЛНЕНИЕ TELEGRAM STARS БОТА
--------------------------------------------------------------------
Чтобы бот мог отправлять настоящие подарки участникам:
У бота должен быть положительный баланс Telegram Stars. 
Вы можете пополнить баланс бота, переведя ему Stars в Telegram или через 
инвойсы/Telegram Business.
Проверить текущий баланс Stars можно прямо из чата командой:
👉 /status

--------------------------------------------------------------------
ШАГ 4. НАСТРОЙКА В TELEGRAM-ГРУППЕ
--------------------------------------------------------------------
1. Добавьте вашего бота в Telegram-группу.
2. Сделайте бота АДМИНИСТРАТОРОМ группы.
3. В диалоге с @BotFather отправьте команду:
   /setprivacy -> выберите вашего бота -> нажмите "Disable"
   (это нужно, чтобы бот видел сообщения и мог разыгрывать подарки).

--------------------------------------------------------------------
ШАГ 5. КОМАНДЫ БОТА
--------------------------------------------------------------------
Для всех участников:
/start   — информация о розыгрыше
/me      — личная статистика полученных подарков
/top     — топ победителей чата
/chance  — текущий шанс и лимит стоимости

Для администраторов чата:
/status              — баланс Stars, статус отправки и группа
/gifts               — список актуальных подарков Telegram с ценами
/togglegift <ID>     — включить/выключить конкретный подарок
/setchance 5         — изменить процент шанса на 5%
/reload              — перезагрузить настройки

--------------------------------------------------------------------
ШАГ 6. ПОСЛЕДУЮЩИЕ ЗАПУСКИ
--------------------------------------------------------------------
Для запуска бота в любой момент просто открывайте:
👉 start.bat
